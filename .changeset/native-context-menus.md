Right-clicking a chat in the sidebar, a step in Progress or a file in Files now opens a native menu with actions for it (open, copy the link, path, command or output, archive), and the app no longer shows the webview's Reload menu. Dragging across the app no longer paints its rows and labels blue: only messages, code and fields select, like a native app.
