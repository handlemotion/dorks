Dorks 0.1.0, the first release for Macs with Apple silicon (M1 and later). Dorks now updates itself: when a new version is out, a blue bar in the sidebar offers it, and Update installs it and restarts the app. Since 0.0.1: crews of dorks that a coordinator runs, many pull requests per chat with stacked PRs and a merge button, named builds for each repository, skills and MCP connectors in Customize, agents that can ask to use your computer, screenshots and images in the chat, and a reworked sidebar, chat details and settings.
