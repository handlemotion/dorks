# Contributing

Dorks does not accept outside pull requests. It is built and maintained by one team, and reviewing code from strangers is a security risk we do not take on.

What you can do:

- **Report a bug or ask for a feature:** open an issue. Include the app version, macOS version and what you saw. Never paste tokens, keys or the contents of `secrets.json`.
- **Report a vulnerability:** follow [SECURITY.md](SECURITY.md), privately.
- **Change it for yourself:** fork it. The license ([Apache-2.0](LICENSE)) lets you. [docs/development.md](docs/development.md) explains the layout and the dev loop.

Pull requests from people outside the team are closed automatically.
